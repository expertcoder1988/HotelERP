# Hotel Management System - Frontend

A modern, responsive hotel management system built with React, TypeScript, and Tailwind CSS. Perfect for video demonstrations and showcasing modern web development practices.

## 🏨 Features

### Dashboard
- **Real-time metrics**: Occupancy rates, revenue, check-ins/check-outs
- **Interactive charts**: Revenue trends, occupancy analytics using Recharts
- **Quick actions**: Fast access to common tasks
- **Today's schedule**: Overview of daily check-ins and check-outs

### Room Management
- **Visual room grid**: Easy-to-scan room status overview
- **Room details**: Amenities, pricing, current occupancy
- **Status tracking**: Available, occupied, maintenance, reserved
- **Search & filtering**: Find rooms by number, type, or status

### Reservations
- **Booking management**: Create, edit, and track reservations
- **Calendar view**: Visual booking calendar for better planning
- **Guest integration**: Linked guest profiles and history
- **Payment tracking**: Monitor payment status and amounts

### Guest Management
- **Guest profiles**: Comprehensive guest information and preferences
- **VIP tracking**: Special handling for VIP guests
- **Reservation history**: Complete stay history per guest
- **Communication tools**: Contact information and preferences

## 🚀 Technology Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom animations
- **Charts**: Recharts for data visualization
- **Icons**: Lucide React for consistent iconography
- **Build Tool**: Vite for fast development and building
- **Date Handling**: date-fns for date manipulation

## 🎨 Design Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern UI**: Clean, professional interface with smooth animations
- **Dark/Light Theme Ready**: Built with theme switching in mind
- **Accessibility**: Proper ARIA labels and keyboard navigation
- **Performance**: Optimized components and lazy loading

## 🛠️ Installation & Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

4. **Preview production build**:
   ```bash
   npm run preview
   ```
