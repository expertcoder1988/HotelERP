# Hotel Management System Front-End — Video Outline (10 Slides)

1) Title — Welcome to the Hotel Management System Front-End
- Tagline: Fast, intuitive, responsive UI for modern hotels
- Visual: Logo, subtle background pattern

2) Problem — What Front Desk Teams Need
- Quick check-ins, clean dashboards, fewer clicks
- Reduce training time, avoid errors, handle rush hours

3) Solution Overview — Core Modules
- Reservations, Guests, Rooms, Billing, Reports, Settings
- Consistent UI, clear navigation, keyboard shortcuts

4) Design System — Look & Feel
- Color palette, typography, spacing scale
- Reusable components: Button, Input, Card, Modal, Table

5) Navigation — Information Architecture
- Global top bar; left-side menu for modules
- Breadcrumbs, search, primary CTA on each page

6) Reservations — Flow Demo
- New Reservation: pick dates, room, guest, payment hold
- Conflict validation, availability calendar, rate plans

7) Rooms & Housekeeping — Status At a Glance
- Room list with filters: Occupied, Vacant, Dirty, OOO
- Bulk actions: mark clean, assign tasks, notes

8) Guests — 360° Profile
- Contact, preferences, stay history, invoices
- Notes, tags, loyalty level, privacy controls

9) Billing & Reports — Accuracy First
- Folios, split charges, refunds, taxes
- Daily summary, occupancy, ADR, RevPAR

10) Wrap Up — Tech Stack & Next Steps
- React, TypeScript, Tailwind, Zustand, Vite
- Roadmap: Kiosk mode, mobile PWA, role-based access
